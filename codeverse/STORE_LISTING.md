## Full description

CodeVerse turns learning to code into a game. Travel through five themed
Realms — Python Peaks, Game Forge, Pixel Studio, Data Delta, and Mind
Machine — each guided by its own mentor character, to learn real
foundations of Python programming, game development, graphic design, data
analysis, and machine learning.

Every level follows the same simple loop: a Story Scene introduces the
idea, a Concept Card explains it, a hands-on Playground lets you try it,
and a Challenge checks what you learned — earning XP, coins, and stars
along the way. Tougher Boss Challenges show up every few levels to put it
all together.

**Built for kids, built for parents:**
- No ads, ever.
- No analytics or tracking of any kind.
- No accounts, no login, no online chat or social features.
- A Parent Dashboard (behind a simple grown-up check) shows progress and
  lets you manage purchases.
- All progress is stored only on the device.

**Free to start:** Python Peaks, the first Realm, is free forever. The
other four Realms unlock with a single one-time PRO purchase — no
subscriptions.

Collect badges, customize your avatar and companion in the shop, keep your
streak going, and climb your own personal rank ladder from Newcomer all
the way to Legend.

## Privacy policy URL
A hosting-ready HTML copy lives at `docs/privacy-policy.html` (same content
as `assets/legal/privacy_policy.md`, just styled for a browser). To publish
it for free via GitHub Pages:

1. On GitHub, go to this repo's **Settings → Pages**.
2. Under "Build and deployment", set **Source** to "Deploy from a branch".
3. Set **Branch** to `master` (or whichever default branch holds this
   file) and the folder to `/docs`, then Save.
4. After a minute or two, the page is live at:
   `https://ashking1981.github.io/my_projects/privacy-policy.html`

Use that URL in Play Console's "Privacy policy" field before submitting.
